# 08 · Evaluation

A production AI system needs measurable acceptance criteria.

| Dimension | Example |
|---|---|
| Quality | Correctness, relevance, groundedness |
| RAG | Retrieval quality, context quality |
| Reliability | Failure and fallback rates |
| Performance | P50 / P95 latency |
| Cost | Cost per task |
| Safety | Injection / policy tests |
| Business | Task completion, time saved |
