# Company Knowledge Base

## Engineering

Production services should expose health checks, structured logs, automated tests, and documented deployment procedures.

## Security

Applications should use least-privilege access, protect secrets through environment or secret-management systems, and enforce authorization before accessing protected data.

## Support

Customer-facing incidents should be recorded with a clear owner, severity, impact, and recovery status.

## AI Usage

AI-generated answers should be grounded in approved enterprise information. If the available evidence is insufficient, the assistant should state that it cannot answer confidently rather than inventing facts.
