# Security Controls — Sample Reference

## Least privilege
Grant users and services only the access required for their duties. Review privileged access regularly and remove access when it is no longer needed.

## Sensitive data
Do not place API keys, passwords, access tokens, personal records, or regulated data in prompts, logs, source code, or sample datasets. Use approved secret storage for credentials.

## Reporting
Report suspected exposure or unauthorized access promptly through the incident-response process. Preserve relevant evidence and do not attempt to investigate beyond your authorization.

## Note
This is fictional learning material, not an official security policy or substitute for a real organization's controls.
