# Password Policy — Sample

## Password guidance
Use long, unique passwords for every service and use the approved password manager. Do not share credentials in chat, email, source control, tickets, or documents.

## Multi-factor authentication
Enable multi-factor authentication wherever it is offered, especially for administrative and remote access. Use phishing-resistant authentication when supported.

## Suspected exposure
If a password may have been exposed, change it promptly using the approved account recovery flow and report the event to the security team. Revoke active sessions or tokens where the platform allows.

## Note
This is fictional educational content, not a real organization's official password standard.
